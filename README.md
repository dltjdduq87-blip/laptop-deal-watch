# 개인 노트북 공개가격 감시

텔레그램 연결 테스트 발송·사용자 수신 확인 완료. 본 프로젝트는 회원 결제창을 자동으로 확인하지 않습니다.

## 실행 범위
- LG 공식몰 노트북 목록에서 최대 8개 그램 상품 발견 + 지정 LG 상품, robots.txt 허용 시 공개 HTML 수집.
- 삼성·11번가 지정 상품은 수집 진단 단계. 차단·사양 누락·정확한 모델 불일치는 오류/미확인으로 기록.
- 가격 150만~300만원, RAM 32GB 이상, 무게 1.6kg 이하, 재고·제조사 공식몰 확인된 공개 표시가 후보만 알림.
- 공개 회원할인가도 개인 적용 자격은 미확인. 배송비·쿠폰·카드·포인트·청구할인으로 확정 실구매가를 만들지 않음.
- 신규 조건 일치 또는 이전 알림보다 낮은 가격 알림. 동일 가격 중복 발송 억제.
- 오류 조합별 하루 한 번 텔레그램 알림, 한국시간 10시 이후 첫 성공 실행에서 하루 한 번 현황. 실행 지연 시 늦게 발송됨.
- 이메일은 SMTP 인증정보가 있을 때만 발송. 기본 미연결.

## 스케줄과 기록
`.github/workflows/watch.yml`은 매시 02,07,12,...57분에 실행을 요청합니다. GitHub Actions는 정확한 5분 간격을 보장하지 않으며 지연·누락될 수 있습니다. Public 저장소는 60일간 활동이 없으면 예약이 비활성화될 수 있습니다.

`watch-state` 브랜치의 `report.json`에 출처 URL, 확인시각, 공개가격, 사양, 원문 해시, 오류를 기록합니다. `state.json`에 알림 중복방지 체크포인트를 저장합니다. 원본 HTML 전체/사용자 채팅 ID/봇 토큰/이메일 주소는 보고서나 로그에 기록하지 않습니다. 체크포인트 저장이 실패하면 재발송될 수 있고, 알림 성공 직후 프로세스가 중단되면 중복 가능성이 있습니다. 텔레그램 성공 후 이메일이 실패하면 같은 후보가 유지되는 동안 다음 실행에서 이메일만 재시도합니다.

중지: GitHub Actions → Laptop public-price watch → Disable workflow.
재개/즉시 검사: Enable workflow / Run workflow.

## Secrets
- TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID: 텔레그램 발송
- SMTP_HOST, SMTP_PORT(465), SMTP_USER, SMTP_PASSWORD, EMAIL_TO: TLS SMTP 발송. Gmail은 일반 로그인 비밀번호 대신 사용 가능한 앱 비밀번호 등 SMTP 인증이 필요합니다. 채팅에 인증정보를 보내지 마세요.

## 미구현/한계
- 네이버·쿠팡·G마켓 수집 미연결. 네이버 기존 쇼핑 검색 API는 2026-07-31 종료, 대체 API 제공되지 않음(공식 공지 참조).
- 삼성/11번가 전체몰 신상품·특가·사전쿠폰 탐색 미구현. 공식 공개페이지 접근 성공이 실제 가격/사양 파싱 성공을 뜻하지 않음.
- KB국민/우리 신용, KB국민/하나/카카오뱅크 체크, 네이버페이는 구분해 미확인으로 기록. 개인 자격·중복·기한·상한 실검증 및 최저 실결제가 자동 비교 미구현.
- AI 개발/게임 벤치마크 자료 미연동. 가격(40), 휴대성(20)은 규칙 기반 점수, AI(30)·게임(10) 및 총점은 null. 임의 종합순위/FPS를 만들지 않음.
- 상품 선택 범위가 제한적이며 전체 시장 최저가 감시가 아님. CAPTCHA/차단 우회 없음. 수집 실패를 '할인 없음'으로 바꾸지 않음.
- 이메일 발송 인증·수신 테스트 미완료. 외부 스케줄러 장애는 해당 스케줄러 안의 코드로 알림을 보장할 수 없음.

## 예산 후보 기준 수정
토스뱅크 체크 및 카카오페이를 추가했습니다. 광고 최대혜택가가 150만~300만원에 들어오는 상품은 공개 표시가가 300만원을 넘어도 후보에 포함합니다. 단 RAM·무게·재고·공식몰 조건은 유지합니다. 개인 결제수단 적용 검증 전에는 광고 후보가로만 알리고 확정 결제액·청구할인·적립 체감가와 구분합니다.
